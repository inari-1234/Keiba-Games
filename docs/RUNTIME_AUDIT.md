# 実行ログの比較検証

2026-09-28 / run 36373555882 / commit 92e8fd7ab467c3e70de08d2d243e3bfd06d699ca。
iPhone 16 / iOS 18.5 / macOS 15.7.9 / Xcode 16.4。

## 方法

ゲームと同じシミュレータに、TextとButtonだけのSwiftUI比較アプリを別bundleでインストール。ゲームの画像・Metal・レース計算・馬券処理を一切含まない。ボタン5回操作で表示がControl 5になることをXCUITestで確認。比較アプリはCIだけのもので製品アプリに同梱しない。
同じログ取得条件で両processのerror/faultを取得。全回帰は省略せず、28単体テスト・2ゲーム操作経路・1比較操作の31件を実施。

## 結論と範囲

XPC・eligibility・Accessibilityの3出力は、ゲームの実装に依存しないことを比較実験で確認した。その他はApple側のキャッシュ／起動計測に関する出力で、今回の検証では描画停止・操作不能・クラッシュを伴わない。全31テスト成功、通常速度75.5569秒、払戻と残高の一致、クラッシュ記録0を併せ、条件18は「検証範囲でアプリ固有の重大障害が観測されない」としてPASSに更新する。
ログのerror文字列が0件になったわけではなく、実機全環境での無障害保証でもない。ログを抑制・削除してのPASS判定は行っていない。前回のgesture timeoutの根本原因は未確定のまま記録する。
